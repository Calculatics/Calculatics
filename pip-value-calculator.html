What is a pip in forex?

A pip is a standard unit used to measure price movements in the foreign exchange market. For most currency pairs, one pip represents a change of 0.0001 in the exchange rate.

For pairs quoted in Japanese yen, such as USD/JPY and EUR/JPY, one pip usually represents 0.01.

How to calculate pip value

Pip value depends on the number of base currency units traded and the pip size.

Pip Value in Quote Currency = Position Size × Pip Size

If the quote currency is not USD, the result must be converted into US dollars using an appropriate exchange rate.

Forex lot sizes explained

A standard forex lot contains 100,000 units of the base currency. A mini lot contains 10,000 units, while a micro lot contains 1,000 units.

For EUR/USD, one standard lot has a pip value of $10 because 100,000 multiplied by 0.0001 equals 10 USD.

Pip value example

Suppose you trade one standard lot of EUR/USD and the price moves 50 pips in your favour.

With a pip value of $10, the estimated gross profit is $500.

If your stop-loss is 20 pips away, the planned monetary risk is $200, excluding trading costs and slippage.

How currency conversion works

When USD is the quote currency, the pip value is already expressed in US dollars.

For other quote currencies, enter the number of US dollars equivalent to one unit of the quote currency.

For example, if one GBP equals 1.30 USD, enter 1.30 when calculating EUR/GBP pip values.

For USD/JPY, enter the number of US dollars per Japanese yen. If USD/JPY is 150, this conversion rate is approximately 1 ÷ 150, or 0.006667 USD per JPY.

Important forex trading considerations

This calculator does not retrieve live exchange rates. Conversion rates must be entered manually for non-USD quote currencies.

Profit and loss estimates assume a constant conversion rate across the selected pip movement. Actual results can differ as exchange rates change.

Spreads, commissions, swaps, slippage, taxes and broker-specific contract specifications are not included.

Stop-loss orders do not guarantee execution at the requested price. Actual losses may exceed the estimated stop-loss risk.
